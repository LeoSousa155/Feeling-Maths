# Feeling Maths 🧮

Um protótipo de plataforma educativa interativa para o ensino de matemática, desenvolvida com React e Vite.

## 🚀 Sobre o Projeto

O **Feeling Maths** é uma ferramenta de aprendizagem focada em tornar o estudo de matemática mais dinâmico. O projeto inclui:
- **3 Temas Base**: Álgebra, Geometria e Teoria de Conjuntos.
- **Questões Configuráveis**: Sistema de exercícios baseado em JSON (`src/data/questions.json`) para fácil manutenção.
- **Progresso Interativo**: Acompanhamento de progresso por tema (em memória).
- **Autenticação Ilustrativa**: Fluxo de entrada simples para personalização da experiência.

## 🛠️ Como Executar

Siga os passos abaixo para rodar o projeto localmente:

1. **Instalar Dependências** (caso ainda não tenha feito):
   ```bash
   npm install
   ```

2. **Iniciar o Servidor de Desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Aceder ao Projeto**:
   Abra o seu navegador e aceda ao endereço indicado no terminal (normalmente `http://localhost:5173`).

## 📁 Estrutura de Dados

Para modificar as perguntas ou adicionar novos temas, edite o ficheiro:
`src/data/questions.json`
